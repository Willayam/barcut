# Code of conduct

Treat contributors with respect. Discuss the work, not the person. Harassment, threats,
discrimination, and the publication of private information are not accepted in project spaces.

Maintainers may edit or remove comments, issues, pull requests, and other contributions that break
these rules. They may temporarily or permanently restrict participation when needed.

Report conduct problems privately to the repository owner through GitHub. Include links and enough
context to review what happened. The maintainer will keep reports private where possible.
