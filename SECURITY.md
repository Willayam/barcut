# Security policy

## Supported versions

Security fixes apply to the latest GitHub release.

## Reporting a vulnerability

Do not open a public issue for a vulnerability or attach private clipboard contents to a report.
Use GitHub's private vulnerability reporting for this repository. Include the affected version,
reproduction steps, and the impact. You should receive an initial response within seven days.

BarCut reads image data from the system pasteboard and stores recent images locally. Reports about
unexpected data collection, file access, or persistence are treated as security reports.
